## 一、定义: 4 级真实可达性

| 级别 | 名称 | 定义 | 用户感知 |
|:----:|------|------|----------|
| L1 | DOM 存在 | `<button>` 或 `<Tab>` 在 DOM 树 | 用户能"看到" |
| L2 | 可点击 | 点击事件不抛错 | 用户能"点" |
| L3 | 有反馈 | 触发 Modal/Drawer/Toast/DOM 变化/URL 变化 | 用户能得到"响应" |
| L4 | 真有效 | 真实业务逻辑执行 (数据提交/查询成功) | 用户能得到"业务结果" |

| 之前报告 | 之后报告 |
|----------|----------|
| 只到 L1 | 本报告新增 L2-L4 |
| "208 路由通过" | "208 路由中 79% 按钮有真反馈" |

### 2.2 判定规则

```
for each button:
  if no onClick handler: L1, 真死按钮 (P0)
  if onClick → noop: L1, 真死按钮 (P0)
  if click throws: L2, 假死按钮 (P1)
  if click → console.error: L2, 假死按钮 (P1)
  if click → 500 response: L2, 假死按钮 (P1)
  if click → no DOM change AND no modal AND no toast: L3, 无反馈按钮 (P1)
  if click → DOM/modal/toast: L3, 有反馈
  if click → business success: L4, 真有效

for each Tab:
  if switch → no content: L1, 空白 Tab (P0 → P1)
  if switch → 500: L1, 报错 Tab (P1)
  if switch → content: L3, OK
```

## 六、根因分析 (5 类)

### 6.1 纯占位 (占 38.2% 真死)

- **现象**: `<Button onClick={() => {}}>功能名</Button>` 或 `<Button>功能名</Button>` 无 onClick
- **原因**: 业务页初版快速搭建, 占位未实现
- **修复**: 补 `() => message.info('功能开发中')` 或 TODO 注释
- **典型案例**: `src/pages/dental/*.tsx` 多处

### 6.2 异步失败 (占 18.4% 假死)

- **现象**: 点击后 console error 或 500 响应
- **原因**: 后端 API 未实现 / MSW mock 缺失 / HTTP 500
- **修复**: 补 ErrorBoundary + 友好提示 + 后端 Stub
- **典型案例**: `qc` 页面 28 处抛错

### 6.3 静默失败 (占 19.8% 无反馈)

- **现象**: 点击后 DOM 无变化, 无 modal/toast
- **原因**: onClick 存在但执行了空操作
- **修复**: 补业务逻辑 + 加载 state + 反馈
- **典型案例**: `regional-report` 22 个 Tab 切换

### 6.4 Tab 切换空白 (占 4.5% P0)

- **现象**: Tab 切换后 Panel 内空
- **原因**: `<TabPane>` body 为空
- **修复**: 补组件或 disabled 该 Tab
- **典型案例**: `data-rpt-ctr` 5 个 Tab

### 6.5 后端未实现 (占 7.6% 500)

- **现象**: Tab 切换触发 API 请求 → 500
- **原因**: 后端 Controller 缺实现 / DB migration 未跑
- **修复**: 补后端 handler 或注释前端调用
- **典型案例**: `notification-ctr` 历史 Tab
