## §1 总体架构 (2000 字)

### 1.1 厂商背景

Infinitt Healthcare 成立于 1996 年，总部位于韩国首尔，前身为 3Di Inc.，2014 年正式更名为 Infinitt Healthcare。公司于 2017 年在韩国 KOSDAQ 上市（股票代码：200580）。Infinitt 是全球领先的医疗影像 IT 解决方案供应商，产品覆盖 PACS、RIS、AI 辅助诊断、3D 高级可视化、远程阅片等全链条。

截至 2025 年，Infinitt 在全球 40+ 个国家部署超过 3,500 套 PACS 系统，服务超过 1,200 家医院。在韩国本土市场占有率约 35%（仅次于 GE 和西门子并列），在中国、日本、中东、东南亚、欧洲、美洲均有分支机构。2023 年公司年营收约 1,800 亿韩元（约 1.4 亿美元），研发投入占比 18%。

关键里程碑：
- 1996: 成立 3Di Inc.，专注 3D 医学影像可视化
- 2008: 推出首代 Web PACS（UniView）
- 2014: 更名 Infinitt Healthcare，构建全栈 PACS 产品矩阵
- 2017: KOSDAQ 上市，加速全球扩张
- 2019: 推出 NX PACS v7.0，重构微服务架构
- 2021: 发布 Infinitt AI 套件，整合深度学习 CAD
- 2023: NX PACS v8.0 发布，支持全模态云端原生架构
- 2025: 推出 UNI 系列统一阅片平台，融合 PACS / VNA / AI

**架构特点**:
1. **全微服务化**: 影像存储、路由、工作流、AI、报告各为独立服务，可独立扩缩容
2. **多云原生**: 基于 Kubernetes 编排，支持私有云、公有云、混合云部署
3. **DICOMweb 原生**: 全面支持 WADO-RS / STOW-RS / QIDO-RS，传统 DIMSE 兼容
4. **分级存储**: 热数据（SSD，7 天）→ 温数据（NL-SAS，90 天）→ 冷数据（S3/Tape，长期归档）自动迁移
5. **灾备**: 支持 Active-Active 双活、Active-Passive 冷备、异地灾备

### 1.6 竞争定位

- **优势**: 3D 渲染引擎（3Di 血脉）；AI 套件完整度（韩国 NO.1 PACS AI）；价格竞争力（约为 GE/Siemens 60-70%）；Web 端性能优异；专科模块覆盖全面
- **劣势**: 中国市场品牌认知度低于 GE/西门子/飞利浦；高端医院装机量偏低；售后响应依赖韩国总部；HL7/FHIR 接口本地化程度不及国产 PACS
- **与 G005 关系**: Infinitt NX 在亚洲（尤其韩国、东南亚）是 G005 RIS 的典型互补型 PACS，其 AI/3D 能力远超市面中国 PACS，适合作为 G005 高端功能对标基准

> **与 G005 差距**: G005 当前为单体 Rails 架构，微服务化仅前端部分。G005 需完全重构为微服务架构方可对标 NX 的 k8s 原生部署、DICOMweb 原生支持、分级存储、多云灾备等能力

### 2.1 多模态 PACS 引擎

Infinitt NX PACS 的核心影像引擎支持 **全模态（CT / MR / XA / RF / US / NM / PET / MG / DBT / CBCT / DX / IO / SC / SM / SR）** 统一管理，在单一工作区实现多模态融合阅片。

**多模态同步核心技术**:

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Infinitt 多模态同步引擎                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  注册中心 (Modality Registry)                                        │
│  ┌──────────────┬──────────────┬──────────────┬──────────────────┐  │
│  │ CT 协议库    │ MR 协议库    │ PET 协议库    │ 融合映射表          │  │
│  │ (200+ 协议)  │ (400+ 序列)  │ (50+ 示踪剂)  │ (CT-MR / PET-CT / │  │
│  │              │              │              │  PET-MR)          │  │
│  └──────┬───────┴──────┬───────┴──────┬───────┴────────┬─────────┘  │
│         │              │              │                │             │
│  ┌──────▼──────────────▼──────────────▼────────────────▼─────────┐  │
│  │  空间配准引擎 (Spatial Registration Engine)                     │  │
│  │  • 刚性配准 (Rigid: 6-DOF)  • 仿射配准 (Affine: 12-DOF)       │  │
│  │  • 非线性配准 (Nonlinear: B-Spline / Demons)                   │  │

│  │  • CT-PET: 彩色叠加热图 (SUV 映射)                              │  │
```

**技术指标**:
- 影像加载速度: 500 帧 CT 序列首帧 < 0.5s（无损压缩传输）
- 多模态同步延迟: < 100ms（同模态系列级联）、< 500ms（跨模态配准）
- 支持最大数据集: 单检查 > 20,000 帧 / 100GB
- 编码格式: JPEG-LS / JPEG2000 / HTJ2K / RLE (DICOM Transfer Syntax 全支持)

**关键功能列表**:

### 8.2 曝光评分（Exposure Score）

自动评估影像曝光参数是否在标准范围内。

**评估维度**:
- CTDIvol：与 DRLS（诊断参考水平）对比，超阈值标记
- DLP：总剂量暴露评估
- kV/mAs 组合：与设备协议标准对比
- 噪声指数（NI）：图像质量与剂量平衡评估
- SNR/CNR：信噪比/对比噪声比自动计算

**评分等级**:
- A (优秀): 剂量 < DRLS + 噪声达标
- B (良好): 剂量 = DRLS + 噪声达标
- C (合格): 剂量 ≤ 1.5×DRLS + 噪声可接受
- D (需改进): 剂量 > 1.5×DRLS 或 噪声不达标

### 9.3 关键差异化分析

**Infinitt 不可替代优势**:
1. **3Di 渲染引擎**: 25 年积累，GPU 加速 WebGL 3D，业界仅 GE UV6 / Siemens syngo.via / Canon Vitrea 可抗衡
2. **AI 套件完整度**: 20+ 临床可用模型，韩国有条件报销（AI 辅助诊断医保覆盖）
3. **专科模块深度**: 乳腺/心脏/骨科/神经四大专科从影像到报告到随访全覆盖
4. **远程覆盖广度**: VmNet + UniView Mobile 从 VPN 到 HTML5 到离线全覆盖

**G005 可追赶优势**:
1. **报告层**: 结构化字段 + 自动评分相对独立于 PACS，G005 可加速自研
2. **AI 结果展示**: RIS 层只需展示 AI 结果，无需自研 CAD
3. **HL7/FHIR 集成**: 标准协议层的补齐对产品竞争力提升大
4. **工作流引擎**: 排班/路由/危急值是 RIS 天然领地，可深度优化

### 10.1 总分评估

|---|---|---|---|

| **影像处理** | 9.5 / 10 | 4.0 / 10 | 3Di 引擎核心壁垒 |
| **AI 集成** | 9.0 / 10 | 1.0 / 10 | 最显著差距 |
| **工作流** | 8.5 / 10 | 6.0 / 10 | RIS 自然领域，差距最小 |
| **专科模块** | 9.0 / 10 | 2.0 / 10 | 专科化趋势 |
| **远程/移动** | 9.0 / 10 | 4.0 / 10 | 远程医疗刚需 |
| **影像质控** | 8.0 / 10 | 0 / 10 | 合规刚需 |

| **总分** | **9.0 / 10** | **3.8 / 10** | Infinitt 是 Full-Stack PACS，G005 是 RIS |

### 10.2 G005 优先补齐建议

**P0（当前 v3.0.6 必须补齐）**:
1. **AI 分检结果展示接口** — 对接第三方 AI，展示 AI 检测框 + 置信度 + 优先级
2. **危急值 NLP 升级** — 报告提交时 NLP 分析 + 5 分钟超时自动升级阶梯
3. **远程双签** — 住院医初诊 + 主治远程审核双签署流程

**P1（v3.0.7 目标）**:
4. **结构化报告字段系统** — SNOMED-CT/RadLex 编码 + 条件字段 + Lung-RADS/PI-RADS 自动评分
5. **DICOMweb 原生支持** — WADO-RS 影像获取取代当前 DIMSE 桥接
6. **HL7 MLLP 双向** — ORM/ORU/ADT 全消息类型
7. **FHIR R4 DiagnosticReport** — 与 Infinitt 等 PACS 的标准化数据交换
8. **AI Orchestrator 平台** — 第三方 AI 算法注册 + 路由 + 计费管理
9. **移动端体验优化** — 触控手势 + 离线缓存 + 渐进式加载

**P2（v3.0.8+ 规划）**:
10. **智能排班 ML 预测** — 基于历史的检查时长预测 + 爽约预测
11. **智能路由规则引擎** — 可视化 If-Then-Else 配置
12. **剂量管理模块** — RDSR 解析 + DRLS 对比
13. **影像质控看板** — AI 质控结果展示（伪影/曝光/体位）

**不需要自研的**:
- ❌ 3D 渲染引擎（对接 3Di / Cornerstone3D / VTK.js 即可）
- ❌ 专科影像处理（利用 Infinitt / GE / Siemens 专科模块 API）
- ❌ AI CAD 算法（集成第三方 AI，不做自研）
- ❌ VmNet 级 VPN（标准 VPN + 流式压缩即可）

**总结**: Infinitt PACS 代表 **亚洲 PACS 的最高水平**，尤其在 3D 渲染、AI 集成和专科模块方面世界领先。G005 作为 RIS，不应试图全面对标 Infinitt 的 PACS 能力，而应聚焦 **报告层 AI 化、工作流智能化、接口标准化** 三大方向，在 RIS 垂直领域做到 Infinitt 级的深度和体验。
