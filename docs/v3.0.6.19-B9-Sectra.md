### 1.2 Sectra VNA 策略详解

Sectra 在 VNA 领域的核心差异点在于 **不以纯粹的"存储集中"为卖点,而以"企业级影像工作流统一"为核心价值**。其 VNA 产品具备以下关键能力:

**1.2.1 多源异构影像采集**

Sectra VNA 支持超过 200 种影像设备类型的数据采集,涵盖:

| 来源类型 | 协议 | 典型设备 | Sectra 支持状态 |
|---------|------|---------|----------------|
| 放射 DICOM | DICOM C-STORE/STOW-RS | CT/MR/DR/DSA | ✅ 原生 |
| 超声 DICOM | DICOM C-STORE | GE/Philips/Siemens 超声 | ✅ 原生 |
| 内镜 | DICOM/非 DICOM 视频 | 奥林巴斯/宾得 | ✅ 支持 |
| 病理 | DICOM WSI + 非 DICOM | 徕卡/3DHistech | ✅ 全玻片扫描 |
| 眼科 | OCT + 眼底照相 | 海德堡/Carl Zeiss | ✅ 原生 |
| 心电 | HL7 + PDF | GE Muse/飞利浦 | ✅ 支持 |
| 临床摄影 | JPEG/MP4 | 相机/手机 | ✅ 归档 |

***(截图占位: Sectra VNA 多源数据采集管理界面)***

**1.2.2 非 DICOM 内容统一管理**

Sectra 的非 DICOM 管理策略采用 **"DICOM 封装"** 方式:将 PDF、JPEG、MP4 等非 DICOM 文件封装为标准 DICOM Encapsulated Document (SOP Class UID 1.2.840.10008.5.1.4.1.1.104.1),使其能够原生进入 DICOM 生态,在企业查看器中统一调阅。这一策略解决了传统 PACS 中非 DICOM 数据"无处存放"的痛点。

| 封装格式 | 对应的 DICOM SOP Class | 展现方式 |
|---------|----------------------|---------|
| PDF 报告 | Encapsulated PDF | 内嵌 PDF 查看器 |
| JPEG 照片 | Encapsulated CData | 缩略图 + 缩放 |
| MP4 视频 | Encapsulated MPEG4 | 内嵌视频播放器 |
| 波形数据 (ECG) | Waveform Storage | 波形渲染 |
| 结构化报告 | DICOM SR | SR 树状导航 |

***(截图占位: Sectra VNA 非 DICOM 内容浏览器)***

**与 G005 差距**:
- G005 当前无非 DICOM 管理能力,依赖文件系统存储外部文档
- 差距评分: ★★★★★ (5/5 显著差距)
- **建议**:G005 在 v3.1.0+ 引入 Encapsulated Document 支持,至少实现 PDF + JPEG 封装
- **优先级**: P1

### 1.4 企业级影像平台的核心设计思想

Sectra 平台的设计遵循 **"三统一"** 原则:

**1.4.1 统一影像存储底座 (VNA)**

所有专科影像(放射、乳腺、骨科、眼科、心内)使用同一套 VNA 存储,而不是每个专科独立 PACS 服务器。好处:
- 患者影像全生命周期统一管理,无需跨系统调阅
- 存储冗余消除(去重 Deduplication),节省 30-50% 存储空间
- 统一备份/容灾/DR 策略

**1.4.2 统一患者主索引 (EMPI)**

Sectra VNA 内建企业级患者主索引,支持:
- 多 MRN 映射 (同一患者在多个系统中不同 ID 的自动关联)
- 概率匹配算法 (姓名/DOB/性别/身份证号多维匹配,阈值可调)
- 人工合并/拆分操作 (审计日志完整)

**1.4.3 统一权限与审计 (Enterprise RBAC)**

- 细粒度权限:按用户/角色/科室/设备/部位/操作类型 6 维度控制
- 审计日志:所有影像访问/修改/导出行为完整记录,支持 HIPAA/GDPR 合规
- 紧急访问模式:在紧急情况下临时授权,自动触发审计报告

**与 G005 差距**:
| 能力 | Sectra | G005 | 差距 | 优先级 |
|-----|--------|------|------|--------|
| 统一 VNA 多专科存储 | ✅ 原生 | ❌ 放射专用 | 架构级差距 | P1 |
| EMPI 患者主索引 | ✅ 内建 | ⚠ 基础 MRN | 缺少多 ID 自动匹配 | P0 |
| 企业级 RBAC | ✅ 6 维 | ✅ 4 维 | 需扩展设备/部位维度 | P1 |

### 2.2 自定义布局系统

Sectra 的自定义布局是行业标杆,其核心设计理念是 **"布局即工作流"**——每个布局模板不仅定义影像排布,还联动工具面板、报告模板、AI 标注层:

**2.2.1 智能布局引擎工作流程**

```
检查接收 → 解析检查类型(CT Chest/CTA Coronary/MR Brain/DR Knee)
         → 匹配科室默认布局(科室主任预设)
         → 匹配医师个人偏好(医师历史调整记录)
         → 动态调整布局(基于 AI 结果: 如肺结节检出时自动增加 MPR 窗口)
         → 渲染到屏幕(支持多显示器独立布局)
```

**支持的布局类型 (50+) 分类**:

| 类别 | 数量 | 示例 |
|-----|------|------|
| 通用布局 | 10 | 1×1/2×2/3×3/4×4 基础网格 |
| 模态专用 | 15 | CT Chest 4 分屏(轴/冠/矢/3D)、MR Brain 6 序列对比 |
| 专科专用 | 10 | 乳腺 4 体位(CC/MLO 双侧)、骨科全长拼接 |
| 对比布局 | 8 | 新旧检查 2×2、治疗前后 4 分屏 |
| AI 增强布局 | 7 | CAD 标注层叠加、AI 置信度热力图侧栏 |

***(截图占位: Sectra 布局模板选择器界面)***

**与 G005 差距**:
- G005 当前仅支持固定 2×2/3×3 布局,无智能匹配
- 缺少检查类型驱动的自动布局切换
- **建议**:实现基于 DICOM Study Description 的自动布局映射引擎(P0)
- **优先级**: P0
